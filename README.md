# ADMISSOR

### Principle Before Prediction.

A deterministic decision-intelligence system built around evidence, authority, traceability, and principled refusal.

ADMISSOR is designed around a simple constraint:

> A system should be able to explain what it determined, why it determined it, and when it cannot legitimately determine something.
